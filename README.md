# PirateShipInventoryManagementSystem
PirateShipInventoryManagementSystem - CS3211.
This project is a PirateShipInventoryManagementSystem, where a user can either be a crewmate or a quartermaster. A crewmate can only add stock, however, if your lucky enough to be a quartermaster you can view the stock changes. The stock contains important information, such as name, quantity, condition, special qualities, and much more! 

BEWARE- Only certain people can log into this secure system. So I will provide some log in details for you to try out:

Crewmate - "John", "Doe"

Quartermaster - "Jane", "Doe"

Chef - "Matt" , "Doe"

Becareful for Jack Sparrow, he already has some gold stored away so you can see how the filtering between crewmates work.
